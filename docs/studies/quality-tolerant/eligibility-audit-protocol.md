## Prospective primary cue candidate: known-weight KL envelope

The existing fixed-M128 empirical-Bernstein ratio construction is retained only as a reference; its analytic infeasibility is already known. Freeze the following alternative for its structural reason: condition on outcome-free cluster sizes/coverage, preserve input weighting, allow arbitrary dependence within components, and account explicitly for the largest component's possible influence. It is chosen before new metadata or simulation outcomes; do not pick a winner after seeing answers.

For numeric cues let c_j be known covered counts; for negation use all-input counts. Drop zero-denominator components from that endpoint only. Write C=sum c_j, w_j=c_j/C, b=max w_j, J=number of positive c_j, H=J*b>=1. For original paired signed losses D_ji in[-1,1], define positive cluster contribution Y_j=sum_i max(D_ji,0)/C in[0,w_j], S=sum Y_j. The original signed point loss remains sum D/C; S is only a conservative bounding statistic. For independent components conditional on this metadata, X_j=Y_j/b lies in[0,1]. Let mu=E[S|metadata]. The target signed conditional expected loss is<=mu.

Proof: for t<0, convexity gives E exp(t X_j)<=1+(exp(t)-1)E X_j. Independence permits multiplying these factors; concavity of log bounds their product by [1+(exp(t)-1)*mu/H]^J. Apply Markov to exp(t sum X_j), and minimize over t<0. For s<mu, P(S<=s|metadata)<=exp[-J*kl(s/H,mu/H)], where kl is binary relative entropy. This does not need identical component distributions or independent sentences inside a component. Invert this monotone lower-tail test: U(s) is the upper root of J*kl(s/H,U/H)=log(1/a), clipped at1; if no root before1 return1. Return a conservative upper bracket after72 bisections plus1e-12, a=.025. At zero s, U0=min(1,H*(1-a^(1/J))). If C=0 return unavailable. Never return a zero-width all-zero confidence guarantee.

This is an explicit derivation for the **conditional known-count input-weighted expected loss**, not a theorem about the ratio of unconditional expected document totals. Those two population targets must not be silently identified when document coverage/size is random and outcome-dependent. No unconditional future-news/year generalization, model quality result or full study readiness follows from validating this candidate. Conditional independence of actual components also remains unproved. Report these scope limits even if the synthetic results look favorable. The proof is our application of the bounded-variable exponential argument; we do not claim to have read the publisher-blocked Hoeffding1963 full text. [Maurer-Pontil2009](https://arxiv.org/pdf/0907.3740), Theorem11, supports the separate reference bound under independent bounded variables.

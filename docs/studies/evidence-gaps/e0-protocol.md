## Frozen statistical procedures

Keep original BLEU/chrF signatures, quality margins 0.5/1.0 absolute points, numeric-F1 margin 0.02, negation mismatch margin 0.02 and practical target >=5% point ready-output reduction with a positive lower bound. Corpus BLEU/chrF use paired sufficient-statistics resampling and direct-corpus parity checks, never a mean of sentence scores. Code pins sacreBLEU 2.6.0. Source equality is a diagnostic selection rule, not a deployable feature.

For E2, retain the plan's three fixed retrospective rules, all 11 fixed comparators and 89 simultaneous two-sided intervals. Per-tail alpha is `0.05/(2*89)`. E4 retains ten prespecified one-sided tests with alpha `0.05/10`; a two-sided display can be added, but cannot replace the gate's stated directions. No alpha from redundant or undefined contrasts is reused.

**Sparse-cue fallback:** let D be the paired candidate-minus-baseline numeric F1, restricted to reference-numeric-covered groups, or paired negation mismatch on all groups. Each D is in [-1,1]. With n eligible groups and k negative / k positive differences, define U(k,n,a) as the one-sided Clopper-Pearson upper probability bound: 1 if k=n, otherwise Beta inverse survival at a with parameters (k+1,n-k). Since expected D lies between minus the probability of any negative difference and the probability of any positive difference, use `[-U(k_negative,n,a), +U(k_positive,n,a)]`. This is conservative and discards magnitude/benefit offsets deliberately; it does not assume F1 itself is Bernoulli. For E4 only the required adverse side is used. A zero-event bound is `1-a**(1/n)`, not zero.

Minimum numeric coverage is the smallest n for which that zero-adverse-event bound is <=0.02, calculated separately for E2/E4 alpha. Less coverage is **inconclusive**, even when no degradation is observed. All undefined coverage is unavailable. Negation uses total group count with the same bound. This confidence construction assumes independent sampled units; if unavailable document clusters are material, state the limitation and restrict interpretation accordingly.

Only O-exact has by-construction equality with the same future final **decoded text for every input**; full-versus-itself is also an identity. Their deterministic text-metric differences are structurally zero, conditional on model execution parity. Observed equality in a finite sample from a causal controller, fixed early depth or another oracle rule is not this structural guarantee and does not bypass cue intervals. A global-optimum certificate remains unavailable.

Bootstrap timing uses ratios of equal-weight identity means. First average repeats within each identity/process block. E1 resamples identities and reports both process blocks separately; it cannot identify process-population variance. E2/E4 resample identity groups and process blocks independently, sharing those indices across all methods; report process-specific sensitivity alongside the crossed bootstrap. Only source/known duplicate groups are available if document IDs remain missing. Freeze balanced method order before any model requests in the later execution protocol.

Monte Carlo precision: for B bootstrap draws and target tail p, record expected tail count Bp, probability of no tail draw, and the 95% binomial rank range. For an execution gate, use conservative order statistics with `k=binom.ppf(0.001/(2*M),B,p)`, where M is the number of simultaneous intervals. Lower bound is sorted draw k (one-based); upper bound is sorted draw B-k+1. If k=0, label the extreme quantile unresolved rather than substitute the empirical minimum as a reliable tail estimate. The extra 0.001 is a reported family Monte Carlo error allowance, not a proof of bootstrap sampling coverage. E2 uses the planned100,000 draws; E4 uses50,000. E0 only simulates the limited representative draws below, plus analytic binomial calculations at those future B values.

Forecasts target eventual Sudoku invalidity, not current acceptance, continuation benefit, truthfulness, safety or language failure. Preserve the producer's negative primary result. ## Interface design

Audience: the researcher inspecting bounded negative experiments. Single job: trace one stopping decision to the recorded prefix and its measured evidence.

Palette: paper #f5f8fc, ink #172c42, blue #235b9a, teal #0f746a, amber #975900, rule #c8d5e4. Bahnschrift display, Segoe UI body, Consolas data, with local system fallbacks. Three work areas: source, selected reconstruction, full-depth comparison; a level rail below the selectors is the signature interaction. Sudoku cells show changes from the preceding level and violations of supplied clues; language levels show literal text and explicitly heuristic cues. No decorative motion, external assets or dependencies. Responsive stacking, keyboard controls, visible focus and readable error/empty states.

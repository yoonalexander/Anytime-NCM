# Retained evidence and source compatibility

The delivery audit is read-only with respect to all research artifacts. It checks the latest closeout source/protected hash families, executed artifact manifests, campaign evidence-bound accounting, packaged aggregate source hashes, unchanged failure/confirmation boundaries and the pinned clean upstream. On the original machine `--private` additionally hashes six already-authorized private cache files without decoding their bodies. No reserved outcome file is opened.

Before any refresh, all three documented final-campaign saved verifiers passed; exact results are retained at [baseline-research-verifiers.json](../../results/delivery/20261029/baseline-research-verifiers.json). They are not represented as strict current-tree passes after metadata changes.

Original README, roadmaps, AGENTS, attributes and Python entry/version metadata are preserved in [the exact-byte archive](../history/pre-delivery-03e3e70/manifest.json). Only those explicit paths can resolve an expected old SHA through archived bytes. Every experimental implementation, protocol, source lock, allocation, result, model-selection record, charge and failure still requires its original expected bytes. An unexpected experimental-file mismatch fails the audit.

```bash
python scripts/audit_retained_evidence.py
python scripts/audit_retained_evidence.py --private
```

The public audit works from a research checkout with the pinned submodule; it is distinct from the dependency-free installed status command. Missing private assets are not replaced with demo data or new inference. The full original phase09 comparison remains incomplete; original phase07 parent resource and phase09 cache terminal state/resource observations are still unavailable. Hash checks cannot reconstruct those missing observations or validate a new population claim.

Original Phase 1-5 and stronger-research reports/manuscripts remain historical. Their published/source-locked bytes are retained by the current audit; software checks do not recompute new quality bounds or reinterpret their cohorts as fresh confirmation. The historical viewer is retained, served and inspected as a saved artifact rather than rebuilt by rerunning experiments.
